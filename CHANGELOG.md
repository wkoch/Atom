# Changelog

Formato: [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/), versionamento SemVer.

## [Não lançado]
### Adicionado
- v0.9 (parcial) — SDKs: `atom-sdk` Rust (sobre `atom-protocol`: handshake, `atom.call`, streams, interceptors + `atom.proceed`, eventos, `kind.load/unload`; `testdata/echo` migrado como prova, `echo_e2e` verde) e `@atom/sdk` TypeScript em `sdks/atom-ts` (mesma cobertura, zero deps, Node 18+, `examples/echo.ts` verificado via stdio); SDK Python adiado para pós-1.0.
- v0.8 — Web: `atom serve --ws` com token (`serve.token` 0600, query ou Bearer, streams fim a fim); `atom/ui-web` shell mínimo (HTTP 127.0.0.1 + `/api/mods|/api/session` + `/mod/<pkg>`, anuncia via `atom.ui.serve`, sem telas próprias); contratos `ui.menu/views/settings/status@0` com pontos semânticos; mods oficiais (layout, menu superior/lateral, settings popup/painel, chat sobre `ai.agent@0`); renderer `single` por ponto via bindings, troca de renderer preserva conteúdo; testes `web_e2e` (WS hello/call/stream/auth + ui-mod).
- v0.7 — Auto-update: self-update do core (release por canal + sig, `ATOM_RELEASE_KEYS` embutida, troca atômica via `self-replace`, health check com rollback, cura de marcador pendente, `.bad`, `prune_bins`); extensões por política (`auto`/`notify`/`pinned`, pausa em cap nova, rollback em falha de ativação); migrações versionadas com backup (`migrate_state` no open); `atom update [--check]`, `atom store gc [--dry-run]`; daemon cura no boot + checagem no boot e periódica; 9 testes (`update_e2e`, inclui N+1 defeituoso que volta sozinho).
- v0.6 — Robustez: grants (`grants.toml`, aprovação na instalação com prompt TTY, `grants list/approve/deny/pending`, `atom.grants.request`, enforcement `service/intercept/events/secrets` no bus+host → `-32003`, filtro `env:`); supervisão com backoff 1s→60s, 5 mortes/5min → `failed` + eventos, `testdata/crash` + teste (não derruba o core); hot reload por pacote (`ext restart`); ativação lazy completa (`onKind` no sync); journal opcional do bus (`[journal]`, `atom logs` com cauda); `testdata/caller` + testes (negação, restart, journal).
- v0.5 — Loja: cliente `store/v1` (config, índice esparso, catalog, ETag, múltiplas sources); verificação em 4 passos (sig índice → sha → sig publisher → manifesto); resolver guloso + `engine` + plataforma + `yanked` + deps; `ext search/info/install/update/rollback`, `source *`, `keygen`, `pack`, `publish --github/--reindex/--check-only`; `atom-store/` de referência com CI; teste e2e (publica, instala em perfil limpo, 1 byte adulterado recusa).
- v0.4 — Kind handlers: `handles`, `kind.load/unload`, `onKind`, `dormant`; bootstrap `contract/runtime/distribution` (`profile create --from`, spawn via `runtime=`); `atom/skill-loader` (+ `ai.context@0`), `atom/mcp-bridge` (stdio+HTTP) como `ai.tools@0`, `atom/runtime-python` (uv/fallback); `testdata` skill/mcp/xyz/py + teste `kind_e2e`; `ui.prompt@0` na `ui-cli` com prompt TTY.
- v0.3 — Hooks: interceptors `before/after/around` + `atom.proceed` (uso único, timeout 30s), eventos pub/sub + `onEvent`, `config_schema`, `atom.config.changed` + `profile reload`, validação de contratos (`-32013`), `atom.register`, `atom/guard-shell` + teste de aceite.
- ADR-016: UI web como shell mínimo + mods componíveis por pontos de contribuição semânticos; architecture, contracts, roadmap v0.8 e glossário ajustados.
- ADR-015: core em Rust (substitui ADR-002, Go); AGENTS.md e roadmap atualizados.
- Especificação inicial: arquitetura, ADRs, roadmap, specs de manifesto, protocolo `atom/1`, capabilities, perfis, loja `store/v1`, atualizações, CLI e contratos iniciais.
- v0.1 — Kernel: workspace (`atom-protocol`, `atom-core`, `atom`), CI Linux/macOS/Windows (fmt + clippy `-D warnings` + test); perfis (`ATOM_HOME`, create/list/use/delete, `profile.toml`); pacotes (`--dev`, `.tar.gz`, `atom.lock` atômico + `.prev`); transporte NDJSON + socket unix (0600) com daemon (`serve`/`stop`/`status`, `call` via daemon ou em processo); bus JSON-RPC com `$ctx` autoritativo; host (spawn, env filtrado, handshake, `onStartup`/`onService`); registry (target → binding → único); KV por extensão + `atom.storage.*`, `atom.config.get`, `atom.log` no host; CLI completa da v0.1; `testdata/echo` + teste de integração do aceite (isolamento por perfil).
- v0.2 — Dogfood: 4 contratos (`ai.llm/tools/agent@0`, `ui.prompt@0`) como pacotes `kind=contract`; extensões `llm-openai-compat`, `llm-anthropic`, `tools-fs`, `tools-shell`, `agent-loop-basic`, `ui-cli` (`atom run chat`); core com streams (`atom.stream.*`, cancelamento fim a fim, `call --stream`), `atom.secrets.*` (keyring + fallback 0600) e CLI `secret`; `contributes.commands` + `atom run` (`onCommand`, TTY via socket); `atom.registry.list` para extensões; `test/fake-llm` + testes `stream_cancel` (cancelamento `-32800`); docs `dogfood-v0.2.md` e `contract-adjustments-0.md`.
